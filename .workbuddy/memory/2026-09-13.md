## 第二轮真机实测修复（glm-5.3-flash，adb 全程验证）

用户连真机（M332BF，Android 17，设备深色模式）实测，发现首轮修复大量无效。逐项修复并在真机上截图验证：

1. **ActionSheet 点击无反应（根因）**：XActionSheet.handleSelect 先 onClose 后 onSelect，命令式 show() 的 Promise 在 onClose 时被 resolve(null) 消费 → 选什么都返回 null。修复：调换顺序（onSelect 先、onClose 后）。真机验证：弹层弹出 + 点「从相册选择」成功拉起系统相册 ✓
2. **上传加号不居中**：Pressable 内 Text 直接布局，安卓上偏下。修复：包一层 flex:1 居中 View（cellCenter）✓
3. **XElevator 仍无效（架构错误）**：SectionList 的 scrollToLocation 不可靠 + 嵌套告警。**彻底重构为 duxui 同架构**：普通 ScrollView + 每组 onLayout 记录 y + scrollTo(y) + onScroll 反推高亮 + 右侧导航「字母 Pressable（点击）+ 容器 onMoveShouldSetResponderCapture（拖动连续定位）」。真机验证：无告警、tap 字母 B 精确跳转、拖动连续定位 ✓。**教训**：onStartShouldSetResponderCapture 的 grant 在 adb input tap（0ms）下不可靠，Pressable onPressIn 可靠。
4. **Menu 样式问题（用户截图）**：遮罩透明度写成 1（全屏纯黑）→ 0.4；快照行无背景（非选中项黑字隐入黑遮罩）→ 加 colorBgContainer 底色；箭头 ▾ 换 ▼。真机验证：触发条显示、面板展开、选中回写「图片▾」✓
5. **上传进表单**：registerXFormProRenderer('uploadImage'/'uploadVideo') 注册（forms.tsx 模块级），XFormDemo 加 photos 字段（Form.Item + XUploadImage），XFormProDemo 加 photos 配置项 ✓
6. **桌面图标未更新**：用户重装的是旧 APK。资源已验证在位（webp 全替换）；需重新构建 APK（本次 gradle assembleDebug 已包含）+ 若 MIUI 桌面仍缓存旧图标需重启桌面/清除启动器缓存
7. **车牌键盘底部安全区**：panel 加 paddingBottom: max(insets.bottom, 10) ✓
8. **逐字签名存字无效（根因）**：非受控场景下 signatureValue 每渲染重置为空 → 存字写入即丢。修复：加 innerValue 兜底 state。真机验证：画字 → 存字 → 顶部字条显示字符缩略卡 + 书写区清空；完成 → 弹层关闭 + 示例下方「签名结果」白底图展示 ✓。普通签名示例同样加结果图展示。
9. **示例页硬编码白色背景在系统深色模式下穿帮**（Section 卡白底白字、Menu 触发条白底白字隐形）：examples/ui.tsx DemoPage/Section 改 useXTheme 主题自适应。**教训：demo 页面严禁硬编码颜色，一律 useXTheme**。
