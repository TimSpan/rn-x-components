# 2026-09-11

## Android 打包准备 + App 显示名称修改

- 确认 `./gradlew assembleRelease` 可直接打包（Hermes 开启、arm64-v8a、产物在 `android/app/build/outputs/apk/release/`）。
- 遗留事项：release 仍用 debug.keystore 签名；applicationId 为占位包名 `com.anonymous.myapp`；正式发布前需生成正式 keystore 并改包名。
- App 显示名称从 "my-app"（Android strings.xml / iOS Info.plist CFBundleDisplayName）及 app.json name "X-Components" 统一改为 `x-components`。改原生文件即可生效，无需重新 prebuild。
